# 即時語音整合 — 動態插件驗收紀錄

日期:2026-02-14(驗收完成)
插件:`voice-1`(動態 Cordis Plugin,最終版本 `pkg-9` / run-8)
範圍:當前 DSH Web GUI × 真實 audio.cpp 8081 端到端語音互動

## 架構總覽

```
瀏覽器 Client(pkg-9)                     Host(pkg-9, DSH 程序內)
┌────────────────────────┐   host.call    ┌──────────────────────────────┐
│ conversation.input.right│ ────────────▶ │ RPC: state/getVoiceConfig/    │
│  通訊圓鈕(藍/橘點)     │               │  setModel/savePreset/...      │
│ settings.section        │ ◀──────────── │ 事件: agent/inbox/claimed、    │
│  三卡片設定頁           │   poll 700ms  │  session/event(assistant/chunk)│
│ shell.overlay toast     │               ├──────────────────────────────┤
└────────────────────────┘               │ bridge 子程序(JSON Lines)    │
                                         │  dsh_LocalAudio/runtime/       │
                                         │  voice_bridge.py (venv python) │
                                         └──────────┬───────────────────┘
                                                    │ HTTP + 音訊
                                        ┌───────────▼───────────┐
                                        │ audiocpp_server :8081  │
                                        │ ASR(sense-asr/qwen3-asr)│
                                        │ TTS(qwen3 家族/voxcpm2)│
                                        └────────────────────────┘
```

- **bridge 職責**(v3 起):8081 存活探測、伺服器啟動(Popen detached)/停止(taskkill 樹刪)、模型清單/卸載/單一化、ASR 收音(sounddevice+靜音偵測)與辨識請求、TTS 合成請求與有序播放(OutputStream)。
- **Host 職責**:round 狀態機(hidden→blue→orange)、turn 關聯(`agent/inbox/claimed`)、串流分句派發(`assistant/chunk` text-delta)、設定持久化(JSON 檔)、Client RPC。
- **熱路徑零外部 exe**:curl/netstat/taskkill/powershell 全數移入 bridge,規避宿主子程序 DLL 初始化不穩定(0xc0000142 事故後的加固;事後 selftest 證實 curl 已可運行,但橋接架構保留)。

## 已知限制與備註

- 設定存於 `dsh_LocalAudio/runtime/voice-settings.json`;永久化時應移轉 DSH Settings namespace。
- TTS 模型懶載入:無 load 端點,預熱以極短合成達成(收音期間執行,10 分鐘快取)。
- 首輪冷啟 TTFT ~12s 屬模型載入;常駐後 ~4s。剩餘延遲底線=DeepSeek API 首句速度+合成時間。
- 動態插件生命週期限當前 DSH 程序;重啟後需重新 run(永久移植為下一階段,模板見 PLAN.md)。
